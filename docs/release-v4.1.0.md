# CoScribe v4.1.0 源码版本说明

2026-10-16。本版在 v4.0.5 基础上整合当前工作区的个人知识助理与对话预测功能，版本号同步更新到 `package.json` 和锁文件。已发布安装包及其验证状态以 GitHub Releases 为准。

## 用户可见变化

- **个人记忆**：在“关于我”中查看、修正、删除记忆，分别控制本地召回、远程使用和自动记录；通过 Markdown 正文、SQLite 来源与修订、按需检索工具支持跨会话使用。
- **学习与关联复习**：记录知识点、技术关注、学习阶段、自评和独立复习事件；关联来源与知识关系，确认材料后加入复习队列；支持显式导入旧闪卡和管理个人学习数据。
- **每日复盘**：基于授权的活动账本和计划生成草稿，预览后确认导出；保留手写内容，检查重复导出、内容冲突与中断恢复。
- **Auto Research**：在文献插件内检索公开论文和仓库，导入资料、尝试下载 PDF/README，生成有证据的文献笔记及综述草稿，确认后写入项目。
- **下一次请求预测**：模型在回答末尾附带后续请求候选，输入框显示淡色文字；Tab 接受后可继续编辑，Enter 发送，Escape 忽略。候选与回答正文分开保存，未接受时不会成为用户消息或记忆。
- **模型兼容性**：Responses 问答通过首条 `system` 消息传递应用规则，兼容忽略顶层 `instructions` 的服务；收紧预测输出协议，并验证流式分片、中文输入法与聊天命令的交互边界。

## 数据与权限影响

全局个人数据存放在 Electron userData 下：记忆正文使用 `assistant/memory/` 中的 Markdown，索引、来源、授权、活动和学习／复习状态使用 `assistant/assistant.sqlite`。数据库升级包含迁移备份、事务、版本校验和中断恢复。项目内继续使用 `.coscribe/` 保存工作区、会话、批注与插件数据；普通助手消息可新增 `nextRequest` 字段，旧会话兼容缺省字段。

IPC/preload 增加个人助理、学习和研究能力，沿用主进程的发送者校验、项目与符号链接范围检查、明确授权和修订检查。网络研究与远程个人记忆分别受授权约束。记忆内容和研究资料作为数据使用；模型返回的写入建议仍需经过适用的预览与确认流程。

研究文献库增加修订以避免并发覆盖。PDF 文本提取与研究资料导入包含读取限额和来源校验。新增助理存储 worker 纳入 Electron 构建；本版没有新增 npm 依赖。

| 检查 | 结果 |
| --- | --- |
| `npm test` | 528 项通过：112 unit、373 Electron、43 AI |
| `npm run test:e2e` | typecheck 与生产构建通过；53 项桌面测试通过，2 项按环境条件跳过 |
| 文档检查 | 变更文档本地链接与代码围栏检查通过；`git diff --check` 通过 |

端到端跳过项分别需要成品可执行文件和原生 ASR WAV 夹具。预测功能另以当前配置的 Responses 服务执行了最小真实请求，验证预测标记能够返回并被提取；该检查不代表所有第三方服务均已验收。交互截图由隔离临时项目的 [预测桌面测试](../tests/e2e/next-request.spec.ts) 生成。
